# UI polish: overlay surfaces (2026-11-06)

Branch `codex/ui-polish`. Tokens live in `frontend/src/features/app-shell/styles/theme.css`.

## Audit findings (ranked by impact)

1. Backdrops differed: `rgb(0 0 0/55%)`, `/65%`, `--ch-color-overlay`, `-soft`, slate 48%; only two had blur.
2. Dialog radius 4-16px (sm/lg/xl/12/16px); shadow mix of popover, dialog, soft, hard-coded rgb, undefined `--ch-shadow-lg`.
3. Twelve component references pointed at undefined tokens (`--ch-shadow-md`, `--ch-shadow-lg`, `--ch-color-surface-hover`, `--ch-color-surface-elevated`, `--ch-color-bg-elevated`, `--ch-color-accent-subtle`, `--ch-color-text-secondary`, `--ch-color-on-accent`, `--ch-color-success-text`, `--ch-weight-medium`, `--ch-font-xs`, `--ch-shadow-card`), so they silently rendered without shadow/colour.
4. No enter/leave motion on dialogs; only TabActionsMenu animated; Goal sheet and others popped in.
5. Mobile: dialogs were top-anchored cards at 760px (workspace) or centered (goal/quota/native), no safe-area handling; only GoalStatusBar was a sheet.
6. Popovers disagreed: border `border` vs `border-strong`, radius md vs lg, shadow soft vs popover, surface vs glass.
7. Dialog titles 17/18/19px, different weights; close buttons vary (text "Close", 28/30px icon, x glyph).
8. Error banner solid saturated red with inverse text.
9. z-index ladder ad hoc (900/1000/1001/1050/1100/1200/1300/1400).
10. Focus rings are mostly consistent (3px accent ring); GoalSetupDialog/ServiceRestart use 2px outlines.

## Changed

- Tokens: backdrop (+blur), overlay/popover radius, elevation aliases, sheet shadow, ease/durations, aliases for undefined names; reduced-motion zeroes durations.
- `overlays.css` (imported in `main.ts`, `:root:root` specificity so it wins over scoped styles): unified backdrop, dialog surface, titles, native dialog backdrop/animation, popover look and entrance, <=640px bottom sheets with safe-area padding.
- Per-component: removed ad hoc backdrop/radius/shadow in GoalSetup, ServiceRestart, AttachmentPreview, Feishu bot dialog, Quota, ArchivedSessions, GoalStatusBar sheet; refined error/auth banners.
